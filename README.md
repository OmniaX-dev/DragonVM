# DragonVM

An emulator for a 32-bit machine (28-bit address bus) that never existed

## Tools
- `dvm`: the machine; `ddb`: the debugger; `dasm`: the assembler; `dtools`: disk tools
- `dsc`: the DScript compiler (a C-like language, see `extra/info/dscript.md`)
- `drun`: runs a machine (or a program) without a window, for tests and scripts
